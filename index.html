📖 How to find the Set ID and Card Number
  1. Look at the bottom-left of your Japanese card
  2. Find the set code first — a short alphanumeric code like SV5a
  3. Right next to it is the card number — it looks like 051/066. The first number (before the slash) is your card #
  4. Enter both values above and hit Match
